Suppose you can send at most m heads.
C:  max t s.t. t//3 <= m ??      t = 3m + 2

During the counter phase, only > reaches the right end of the tape.
> C1 P X^n R
< C2 P X^n R
...
> C2 P X^n R
F > P X^n R
F w> X^n R
F Y^n w> R
F Y^n < X R
F < X^n+1 R
< C X^n+1 R
...
> C X^n+1 R
< C1 X^n+1 R
...
> C1 X^n+1 R
< C2 X^n+1 R
...
> C2 X^n+1 R
F > X^n+1 R
F < C1 P X^n R
(cycle)

(thus tape configuration ...C P X^n R appears to be impossible given the block level rules, since
when a new base 3 digit is generated it is as "C1 P".)

Reset phase:
After counter on left side overflows, it generates 
a w> head that makes it all the way to almost the right side, eventually resulting in 
one of these five cases:
w> C1 P X^n R
w> C2 P X^n R
w> C X^n+1 R
w> C1 X^n+1 R
w> C2 X^n+1 R
