so there are four possible configurations at the left side of the tape.

The effects on the stride components' exponents to the right:
L3 >     : -1, +1, -2, +2, -4, +4, ...
L0 C >   : -1, +1, -2, +2, -4, +4, ...
L3 C0 b> : +1, -2, +2, -4, +4, -8, ...
L0 X b>  : +2, -2, +2, -4, +4, -8, ...
            * first +1, then +1 when the head returns left due to the extra X
total    : +1, -2,  0, -4,  0, -8, ...

As a result, I'd expect digit collisions to almost always result from the 2nd half of 
(2nd, 4th, 6th, ...) exponents going to zero. Also, these collisions should only happen
after L0 X b>, since L3 > and L0 C > actually increase the 2nd half of exponents and
L3 C0 b> only serves to undo the increase of the preceeding L3 > and L0 C > and thus will
not push the 2nd half of the exponents to a new low.

Approximate effect on nearby exponents due to digit collision:
N0 n0 N1 n1 N2 n2 ...
then let's say n0 goes to zero.
N0 0 N1 n1 N2 n2 ...

N0+N1 n1 N2 n2 ...
