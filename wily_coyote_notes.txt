attempt at backward reasoning
==============================

> P R -> < D F R
> Q R -> < X P R
> R -> ***HALT***
s> R -> < C X P R

I haven't gotten an easy solution by backward reasoning. RIP.

The right end starts off as (step 13) ... D F R.
If the head is s> when it reaches R, then the TM is safe and will not halt, but if the head is > then it will halt.
We need to find some closed set of situations of a rightward head and configurations at the right end of the tape.

Possible rightward heads:
s>
>
> P
> Q
The last two can lead to regrouping of symbols.

D Q R = 111$ is not safe enough:
> D Q R
X s> Q R
X Q > R
HALT

Possible situations at the right end of the tape (actually seen in simulations):
PDQR = CDR = 2111$
DFR = 1122$
CFR = 2122$
QCQR = XDR = 1211$
XFR = 1222$

CXPR is redundant: CXPR = 2 1122$ = P DFR
DXPR is redundant: DXPR = 1 1122$ = Q DFR

DFR closed.
CFR closed.

> P CDR -> ...1111$, a new configuration
> Q CDR halts

s> XDR -> ...1121$, a new configuration
> P XDR -> ...2211$, a new configuration

s> XFR -> ...1112$, a new configuration
> P XFR -> ...2222$, a new configuration

s> XCDR ->  ...111111$, a new configuration
> Q FCDR -> ...111111$
> FCDR -> ...112111$, a new configuration

> DDDR halts. this does not seem to work very well.

add situations?
XCDR = 122111$ (from > Q DFR)
FCDR = 222111$ (from s> CFT)
DDDR = 111111$ (from s> XCDR, > Q FCDR)
