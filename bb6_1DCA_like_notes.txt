It turns out that we will need some matrices.
Let S_n, T_n be 2^n x 2^n matrices whose elements are in Z_2 (addition and multiplication modulo 2), defined as follows:
S_0 = T_0 = [1].
S_n = S_n-1 S_n-1
      S_n-1   0
T_n =   0   T_n-1
      T_n-1 T_n-1

Then,
S_n T_n = T_n S_n = I_(2^n) (identity matrix)

This is trivial for n=0.  For larger n, can inductively prove. Quick sketch:
[[S S]  [[0 T]   = [[ST 2ST]  = [[ST 0]  = [[I 0]  = I
 [S 0]]  [T T]]     [0   ST]]    [0 ST]]    [0 I]]


Claims, for H and B being 2^n heads and 2^n symbols:
H(B) = B + S_n H
B(H) = H + T_n B + e0,n

Here, B, H are re-written as column vectors.
e0,n is a vector of length 2^n where the first element is 1 and the rest are 0.
Addition is modulo 2.

For n = 0, this follows after we interpret the h and b in (1) as vectors of length 1.

For larger n, we can prove by induction.
Assume the inductive hypothesis for n; we seek to prove it for n+1.
As before, split H and B in half:
H = [[H1]   B = [[B1]

H2(B1) = B1 + S_n H2
B1(H2) = H2 + T_n B1 + e0,n
H1(H2(B1)) = B1 + S_n H2 + S_n H1 = B1 + S_n (H1 + H2)
